# PPO 价值损失权重对照

从服务器现存的 control-s1 示范初值热启动，新建实验，不恢复历史优化器。初值 SHA256 为 `f05c7c5d9452a26c9e8e1507d88a13737e3353a565cb87b7e5bb7d37e9c1fefe`。

两组都关闭熵奖励及参考 KL，保留 detached 价值特征；唯一训练参数差异是 `vf_coef`：对照 0.5，实验 0.00005。每组固定 262,144 步，64 环境、4 个仿真线程、1 个 PyTorch 线程，CPU 串行执行。训练地图 01001000/01004000/01005000/01006001，等级 1/4/8/16；守方预建造 900 tick，出生距离保持 1.0。

假设：减小价值损失对全局梯度裁剪的影响可能缓解策略退步。它不等于回报归一化，也不保证修好价值估计。本次更改批量大小，不能把新结果与旧 16 环境实验直接拼接；重新训练同批量对照。

训练后比较初值、对照及实验最终检查点。三张留出图 01007000/01008000/01009000 × 等级 1/4 × 每项 32 局，固定 argmax、种子 100001/200001/300001。实验须对两个基线在每项的胜局与建筑价值都不退步，且各有至少一项提升，才通过本轮门槛。不挑中间最优权重、不修改正式游戏模型；采用仍需独立训练种子和真实多波验证。

入口为 `train/value_scale_pilot.py`，须指定全新运行目录、初值路径和 SHA256。计划、状态、训练日志、检查点及逐案例报告均保存在该目录。失败时记录失败阶段，不覆盖历史目录。

启动前本机实测：3 项 PPO 冒烟、38 项运行时回归、2 项预建造命令行测试通过。命令行测试同时修复采集及评估错误沿用默认距离课程、导致合法完整距离被护栏拒绝的问题。
