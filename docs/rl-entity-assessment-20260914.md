# pooled / entity 训练机制评估

实验日期：2026-09-13；整理日期：2026-09-14。冻结源码 fb97545，六个实验均完成 131072 环境步（32 次 PPO 更新）；只做读取和独立诊断，无训练续跑、无部署。

## 结论

保留 entity 作为候选，不判定优于或劣于 pooled。共同回报数据支持其预测能力，但没有稳定的控制收益。优先检验近乎确定的热启动策略与探索、估值误差对优势信号的影响，以及训练截止语义；不应立即归因为共享团队优势错误，也不应立即增加网络复杂度。

## 核验与实测

- 114 个冻结文件哈希均匹配；六组环境步数正确，actor 权重没有非有限数。
- 两组 actor 架构、初始化来源、任务及超参数一致；修改的是团队 critic。entity 为逐编队 MLP 编码后均值/最大值汇总，既不是注意力通信，也不是逐编队贡献估计。
- 参数量并不匹配：pooled 22529，entity 30785。因此结果不能单独归因于结构优势。
- 在同一组 2143 个状态、48 段完整基线轨迹上重算有限回合真实折扣回报预测。按既有划分取未用于预拟合的 22 个完整回合，最终 RMSE：pooled 三种子 321.99 / 328.37 / 330.99；entity 267.46 / 271.14 / 285.48，分别降低 16.9% / 17.4% / 13.7%。预拟合时是 315.80 对 274.88。
- 此数据是旧策略轨迹，不是最终策略的在策略价值真值；验证划分只隔离回合，没有隔离地图/入口。最终策略变化会改变应预测的回报，因此不能把相对旧回报的漂移都叫作遗忘。日志中的 GAE 目标解释方差还存在各组数据与自举目标不同的问题。
- 新采样诊断使用冻结基线动作采样种子 993001，在 episode_spec 前 1000 项中覆盖全部 26 个不同地图/等级/入口组合。抽取 7160 个编队决策观测，平均合法动作数 9.626，全部有多个合法动作。基线最大动作概率均值 99.694%，熵 0.00963；最终模型最大概率仍为 97.76%–99.43%。最终首选动作相对基线改变 0.461%–1.006%。这说明共同状态上的决策变化很小，不说明最终策略自己的轨迹也完全不变；少量关键动作足以导致后续路径分叉。
- 训练每次更新平均 KL 很低，未见大面积 PPO clipping；没有证据支持“学习率过大导致整体策略崩溃”。低熵在热启动时已经存在，不能说 entity 导致了探索坍塌。

## 评估面板重新解释

每种子 48 条记录覆盖 26 个地图×等级×入口组合；同组合不同 world_seed 的统计量未必相同，但本轮终局类别在 120/240 秒两个窗口均一致。按组合等权计算：

| 时间窗 | pooled（三种子） | entity（三种子） |
|---|---|---|
| 120 秒 | 15 / 13 / 13，共 41/78 | 12 / 12 / 15，共 39/78 |
| 240 秒 | 17 / 15 / 15，共 47/78 | 15 / 15 / 16，共 46/78 |

78 是三个种子的重复局面测试，不是 78 个独立地图。不使用普通二项分布置信区间声称显著差异。剩余非胜局均仍为超时，未出现攻方全灭，不等于已败。

entity 种子 1、2 从 65536 到 131072 的下降都集中在 gen_01009000、等级 4、入口 0/3；种子 3 则改善。没有普遍退化证据。最终 entity 的平均建筑拆毁价值三个种子均略高，但幅度小；守军击杀价值、自损方向不一致，不能只看拆楼价值宣布更好。

## 源码确认的机制限制

1. 团队优势广播给活编队是合法的合作策略梯度做法，不是“奖错了”的直接证据。它没有显式反事实贡献估计，但是否为当前瓶颈需实验证明。按活编队展平、逐小批标准化、逐编队 PPO clipping 还会影响实际样本权重；不要将重复相同标量等同于重复独立证据。
2. critic 先对每个 15×15 局部观测做通道均值/最大值，空间布局已丢失；actor 仍使用 CNN，不能说 actor 同样看不到局部空间。entity 没有给 actor 添加通信或更丰富观测。空间不足是共同限制，尚非失败原因。
3. 训练 max_ticks=2400 是明确有限单波终局，GAE 在该边界不自举；240 秒仅是评估续跑，没有训练覆盖。不能宣称已把训练超时延长。观测 globals 只有波数与空中存活比例，自身向量也无剩余时间；有限时限任务对无记忆网络存在时间信息缺失。若保留有限任务应测试剩余时间；若改成持续任务须有真实连续城市状态，不能跨新局自举。
4. gamma=.99 每 0.3 秒折扣，未来收益权重半衰期约 20.69 秒；GAE 的 gamma×lambda=.9405，20 秒后的直接残差权重约 1.67%，更远信息依赖价值自举。机制本身合理，参数是否适合长距离配合需独立对照，不能与结构同时随意修改。

## 建议的下一轮（尚未执行）

先保留 pooled/entity 双臂，并使用相同采样预算和完整训练随机种子。第一优先做受控探索对照：同一热启动 actor，小幅降低输出 logits 尺度以放松过度确定的分布，与原热启动比较；先验证有效动作概率、局面覆盖及基线性能，避免直接大幅加学习率。两种 critic 都做相同处理，以检验交互效应，不从单独 entity 改动推断因果。

增加固定轨迹的优势诊断：同一 rollout、同一 actor 比较两种 critic 给出的 TD/GAE，检查关键转折的符号、终局附近误差、共享参数梯度方向及训练后的动作概率。现有报告只证明估值与动作分布两个环节，尚未直接定位中间梯度因果。

评估同时报告 frozen_argmax 和 frozen_sample：原来只用 argmax，概率改善可能未跨越首选动作阈值。对 26 种组合等权，随机采样使用多个 action seed；120 秒与 240 秒分报、超时保留截尾语义，并持续报告拆毁价值、守军击杀与自损。固定检查点用于配对比较，选模型的数据与最终评估分离。

截止语义与剩余时间作为另一个独立实验，不与探索/critic 一起改。保留现有冻结产物，先小规模诊断，不直接追加百万步。

## 数据定位与复查方法

本报告基于 PR #183 的 fb97545；pooled/entity 两臂均使用团队优势，不是“个体信用 vs 团队信用”的对照。pooled 是继续训练的对照组，另有两臂共同初始化的冻结 baseline actor。

原始数据保留在实验服务器 `/home/yys/Cody-ic/runs/`，未将模型权重、轨迹或生成日志提交到仓库：

- `review-extension-20260913/plan.json`：冻结哈希、65536/131072 检查点、两臂和三种子。
- `review-extension-20260913/seed-{1,2,3}/{pooled,entity}/`：配置、价值诊断、PPO 日志及最终检查点。
- `review-extension-20260913/summary-s{seed}-{arm}-131072.json`：逐地图/等级评估、入口、战果及 timeout_review。
- `review-pilot-20260913/data/baseline.npz`：新奖励下的共同完整回报数据；`episode-split.json` 只复用其中 splits 的回合归属，不能把该文件遗留的旧拟合 rows 当成本轮结果。
- `entity-audit-20260913/{audit,action-audit,outcome-audit}.json`：此次对照结果。

价值误差复查：载入每组 latest.pt 的 team_model，恢复 offset/scale，在 baseline.npz 上前向预测；按 splits.baseline.validation_episodes 选回合，对 prediction−target 计算 RMSE。该验证不等价于未见地图泛化或最终策略在策略评估。

动作复查：冻结 baseline actor 采样种子 993001；枚举 episode_spec 前 1000 项并按地图/等级/入口去重，得到 26 种组合。每 8 个决策步采样活编队观测，把同一观测交给 baseline 和六个最终 actor，应用相同合法动作掩码后比较分布；不更新参数。决策观测相互相关，7160 不能当成独立统计样本。服务器脚本 `entity_action_audit_20260913.py` 的历史注释写 30，实际只找到 26；以输出 scenarios 为准。

结果复查：按地图/等级/入口分组，在组内平均胜利指标，再对 26 组等权汇总；分别使用原 end 与 timeout_review.end。同组两时间窗的终局类别本轮一致，仍不能声称所有轨迹完全相同。
