# 配平第一步：按侦查选择进攻方向（#167 D）

原主攻方向由波次取余决定；现在在上一轮侦查快照中记录每个集结点对应
城墙入口的箭楼覆盖数。若原轮换入口与另一入口都已探索，选择覆盖更少的入口。
覆盖相同、原入口未知或旧存档缺少方向情报时维持轮换；佯攻仍在相邻集结点。

入口是集结点向原始城墙环的投影，覆盖使用数值表箭楼射程及迷雾中的建筑记忆。
只有该入口整个潜在射程区域已探索，才能视为已知；未知区不会被当成零防御。
这是脚本启发式，未估计实际绕路、守军、塔等级、齐射效率或新扩建的墙环。
不死鸟防空规避、维修价格、塔价、施工时间均未在本次改变。

情报仍只在既有侦查成功路径更新，并在下一波生成时冻结。玩家未被看见的新塔
不会改变选择。方向数组进入两个情报快照字段的通用存档编码；旧 v4 缺字段
按无方向情报读取。规则行为有变化，不承诺旧操作日志跨版本逐拍一致。
