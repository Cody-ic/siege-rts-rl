# 防空突破与破墙代价核验

[通关复盘](README.md) · [90波续局](guard-route.md) · [逐波分析](waves.md) · [突破代价](breakthrough.md) · [策略对照](counterfactuals.md) · [实验核对表](counterfactual-tables.md) · [逐条事件](events.md) · [核对表](supporting-tables.md) · [证据与复现](evidence.md)

本专题核验v1.0.1同一条成功路线的实际事件与公式，使用回档前冻结日志。随后完成的35组改规则局部对照单列于[策略对照报告](counterfactuals.md)；两者均未改变正在玩的游戏或存档。

## 1. 判断应从“覆盖多少”改为“能否付得起突破的代价”

这两种情况有同一个要点：守方火力点和障碍都可以被消灭，攻击后的战场会变化。防空射程画得再大，如果不死鸟可以先拆掉它，覆盖也可能很脆弱；一段墙看似挡路，如果破墙比绕路少挨打，直接突破反而更安全。

因此，覆盖比例可用于寻找候选区域，不能单独作为是否派鸟、是否绕墙的判决。需要比较接近损失、突破损失、突破后的作战收益，以及撤回或继续进攻的可能性。

## 2. 第55波已经出现了“拆掉防空后继续打塔”

74级不死鸟（实体5701659）满血785；一级防空（实体34078720，地图中心99.5、74.5）满血450。逐次扣血日志如下：

| 事件 | tick | 结果 |
|---|---:|---|
| 防空第一次命中 | 127313 | 不死鸟785→740 |
| 鸟先拆三段木栅 | 127327—127487 | 每段两击；这一阶段持续受到防空攻击 |
| 鸟开始命中防空 | 127519 | 防空450→324 |
| 后续三击 | 127551、127583、127615 | 防空324→198→72→0 |
| 防空累计命中8发 | 最后一发127590 | 共360伤害；鸟仍有425血 |
| 下一次受到伤害 | 128311 | 来自登墙弓手；距防空拆除34.8秒 |

这34.8秒内，鸟又拆了两段木栅，对五座箭楼造成2142伤害。此处没有把主动拆塔算成鸟直接击毁，也没有把整个后续区域宣称为永远安全；它随后确实遭到弓手攻击。

这证明的是：**该处防空覆盖可以被突破，而且突破产生了真实的后续输出机会。** 原局并未主动优先拆防空，反而先打了木栅。后续射程内防空优先实验将拆除提前3.2秒，但鸟在整波多承受29伤害、多输出126建筑伤害；局部先手没有直接转化为更好的存活余量，详见[局部对照](counterfactuals.md)。

后半程鸟共直接拆掉8座防空：五座一级、两座二级、一座三级。只数防空数量，既不反映等级，也不反映重叠火力能否在鸟拆完之前将其击落。

本例防空每击45，若鸟一直保持785满血起算，需要18次命中才足以击落；鸟打建筑每击126，拆450血防空需要4次。真实日志显示鸟连续攻击间隔32tick，防空约40tick，弹丸飞行会影响到达间隔。射程先手、接近路线、交叉火力、墙上弓手、维修以及已有残血均必须另计，不能仅凭“4次对18次”给所有场景判胜。

## 3. 寻路高估破墙时间，并且没有估算沿路承伤

当前流场将行走时间和破坏时间相加。行走按距离除速度；破坏按“所需命中数×（前摇+冷却）”。这套代价没有累加沿途塔火伤害，没有估计多人一起破墙，也没有预测维修速度或破口被补上的可能性。

另有两处可核实的偏差：

1. 等级只分1、4、8起点的三档，高档用8级作为代表。调用方使用默认档界，所以99级部队也按8级的结构伤害估价。
2. 实战前摇与冷却同时开始，持续攻击的周期不是两者相加。把每击都按两者相加计算，再加上错误等级，会进一步夸大破墙代价。

### 第69波单锤实例

99级攻城锤6684679对一级满血墙每击646。它在tick160091开始前摇，160121第一次命中，160151开始第二次前摇，160181拆墙。**从首次前摇到拆墙是4.5秒。** 两段相邻1200血墙同时受到它的范围伤害并被拆除；这两段在该受击窗口没有其他单位帮打。

流场对同样1200血墙按8级217伤害估计6次，每次计90tick，破坏项为27秒，是这段实际交战时间的6倍。仅改成99级但保留原周期公式仍会估为9秒；需同时校正代表能力和时间模型。

这是破坏代价项的核验，**没有证明当时存在一条绕路路线恰好多损失多少，也不是端到端寻路提速六倍。** 实际追踪中的锤已经选择了破墙；此例揭示估价失真，不能被写成这只锤绕路失败的证据。

普通亡灵同样受影响：99级结构伤害23，1200血单兵需要53次；8级估价伤害8，需要150次。按当前公式会从真实等级下的71.55秒夸大到202.5秒。持续攻击的理想交战时间约57.45秒，但多兵并行、接敌空间、守军打断和维修会改变结果，不能按人数简单均分。

## 4. 更合适的策略判据

对不死鸟，先生成“绕开、先拆一处防空、协同集火、暂缓”的候选计划，再估计接近和击毁期间收到的有效伤害、击毁后开放的目标、其他防空和登墙弓手的支援，以及鸟的存活与后续波次价值。先拆防空应是一种可选手段，不能再改成无条件最优先。

对地面编队，比较“现有缺口绕行、就近集火破墙、先拆威胁塔、换入口”。用预计战损、到达后的有效兵力、目标收益和耗时一起判断。破墙后还必须穿过缺口并形成持续压制；守方能快速补墙，单纯打出一个洞不是成功突破。破口被重建或塔被拆掉后应及时重算，并保留短暂任务承诺避免来回改主意。

火力估计要基于合法已知信息；同一防空不能在预测里同时对每只鸟兑现全部单体伤害，同一片箭雨却可能伤到密集的多个地面单位。应估算有多少单位真正接敌，而不是用全编队面板DPS假设所有人同时攻击。

## 5. 下一步验证应分层进行

| 对照 | 改变什么 | 重点观察 |
|---|---|---|
| 单位与防空的局部交战 | 防空等级、数量、交叉覆盖；鸟当前血量与集火数 | 击毁时间、鸟损失、拆后输出与安全撤离 |
| 同一阵地的突破选择 | 绕路、集中破墙、先拆塔 | 到达目标的存活兵力、战损、破口维持时间 |
| 守方能响应的连续对局 | 玩家或守方能补墙、抢修、补防空 | 真实资源交换、堡垒威胁、策略是否只靠守方不响应 |

先单独校正等级与攻击周期，再单独加入火力估价，再试集火和任务协同，才能判断改善来自哪里。不要一次同时更改敌军数值、配兵和目标规则。

已完成源码和原局事件核验，并追加5个波次、7种模式的[局部对照](counterfactuals.md)。其中单独校正周期、单独校正等级及二者组合均已运行，也已探索射程内防空优先、塔下不等队形；上表中系统改变防空配置、引入火力估价/指定目标协同及可响应连续对局仍待验证。
