# 建造交互：强制抢修、活墙朝向与拖线放置

本批实现提案 #164、#168、#169；不包含不死鸟、剧情彩蛋及平衡数值提案。

## 操作

- **强制抢修**：先对受损建筑下达维修，或开始新建/升级工程；选中工匠，Shift + 右键点目标建筑。橙色标记表示正在执行强制单。工匠忽略风险，仍受通行规则限制；仅认领指定工程。工程完成、目标被毁或工匠死亡后失效。普通右键可覆盖强制单。
- **放置模式**：按 B 或点底部“建造”，默认选择城墙；Tab 按墙、门、木栅、箭楼、弩楼、采集建筑、兵营、瞭望塔的顺序切换。也可从空地建造菜单选择类型。
- **连续建造**：放置模式只拾取地面，高建筑精灵不会抢走落点；左键松开提交，之后保持模式。该模式不框选单位。
- **拖线建墙**：墙/木栅按住左键拖动，沿位移较大的轴展开；平手选横轴，Shift 改用另一轴。绿为可提交，红为点位无效，灰为剩余库存不足。HUD 展示整条预览的数量、总报价与库存；只提交有效且依次买得起的段，最终裁决仍由世界执行。
- **退出**：右键或 Esc 退出放置模式；该次右键不会再给单位下令。进入菜单或日记也取消模式。松手落在 HUD 或地图外时取消本次拖线。

木栅同样自动朝向：参考相邻木栅、城墙与城门（含工地），拖线预览使用同一规则；转角补另一轴，拆除后立即更新，孤立段默认竖向。木栅不会改变已有城墙的走向。

## 墙体与存档

对局的横墙、竖墙、拐角及墙上士兵的拾取高度统一读取活墙/门，包括工地。拆墙后重新判断邻居；孤立墙默认竖向，仍有左右邻居的缺口边缘保持横向。静态地图查看器保留原规则。

强制单绑定单位世代和建筑句柄，槽位复用不会继承旧单。新增快照字段兼容缺少这些字段的旧普通工单，操作日志支持强制单恢复。世界布局、世界哈希标记、回放格式与训练侧默认脚本不变。

## 验证

Windows/MSVC Release，使用 CMake 构建并运行 CTest。回归覆盖新建横墙、工地/门、拆墙拐角、非墙邻居、拖线轴向与顺序、预算及重复格、危险区强制施工、工程完成回避、单位/建筑槽位复用，以及快照与操作日志恢复后的逐步世界哈希。

2026-09-10 本地验证：`build-Render2`（渲染开启、ONNX 关闭）完整 CTest **155/155 通过**，耗时 202.55 秒。1500×1000 与 960×540 的放置截图已目视检查；未进行真人鼠标交互试玩。新版程序为 `build-Render2/render/rts_render.exe`；根目录 `play.bat` 的旧目录搜索不会优先启动此构建，请直接运行新版程序。

新增截图测试 `render_live_wall_shot` 和 `render_placement_preview`。后者使用真实游戏的放置绘制路径，包含绿色可建段、红色非法段和灰色预算不足段。截图输出位于构建目录的 `render/`。

测试过程中修复了三个既有渲染探针的 Windows 命令行编码问题，以及存档测试的中文路径转换。批量脚本旧临时依赖路径失效时，可让 CMake 重新下载锁定依赖，或指定仍存在的源码目录。
