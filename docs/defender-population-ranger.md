# 人口扩容、猎骑冲锋与建筑驻守

本批基于 #202，在 #204 中实现人口扩容、猎骑主动接敌和指定建筑驻守。以下为当前实现，数值仍需长局试玩校准。

## 人口

工匠与战斗守军共用的人口上限由 `8+2K` 改为 `8+3K`，K 为堡垒等级。UI、征兵校验和训练环境使用同一上限；斥候含在训不计人口，工匠计入人口，无玩家工匠比例限制。

## 猎骑冲锋

猎骑接入已有的骑士动量机制：移动累积助跑，每格增加首击伤害18%，4格封顶，即最多增加72%。攻击落地消耗动量，停步清空；持续贴身攻击使用基础伤害。没有自动退出重冲，也没有回血、付费休整或遣散系统。

猎骑会主动迎击驻点8格内的可见地面敌人，自动接敌路线最长12格，优先考虑路线接近的法师和攻城锤；不因血量低、敌人等级高或敌众我寡拒绝出击。无目标后回岗。路径通过实际城门与巷道，不可达时显示受阻，不冲撞己方墙体。跨格重新采样路径，保持20 Hz仿真和原决策节奏。

沿用现有属性关系，亡灵步兵的反冲锋会作用于有动量的猎骑；猎骑不是枪阵，本身不获得反冲锋伤害。基础血量、普通伤害和速度不增加。

反冲锋读取本拍单位战斗开始时的动量，避免同一拍内骑士先攻击并清空动量，令后结算枪卫丢失加成。该快照仅为本拍临时数据，不新增永久单位状态；其他战斗仍按原有顺序结算。

## 指定建筑驻守

- 选中猎骑、枪卫或弓手，右键建筑即可守在周围。可以保护城外矿场、兵营、塔楼和施工现场，不需要新按钮。
- 弓手右键完工城墙或城门仍执行登墙；同组枪卫、猎骑在地面守卫。其他建筑不提供登顶、防空或高度加成。
- 驻守部队处理附近可见敌人，地面弓手保留近战靠近时的拉扯，战后返回指定建筑；岗位跨波、存档和操作日志重放保留。选中时显示目标建筑与驻守状态。
- 右键另一个建筑改派；右键空地解除建筑绑定。猎骑改为守该坐标，其他兵种恢复原来的临时移动语义。
- 建筑被毁后守原地；同格重建不会继承旧绑定。阵亡士兵的岗位不会转交给复用槽位的新兵。工匠和斥候不接受战斗驻守任务。

## 寻路与验证原则

驻守回岗与清野统一使用完整A*，按已走距离加到可站立目标格的曼哈顿距离下界排序；不先用贪心返回，不设固定局部边界来误判远处城门不可达。目标不可达时显示受阻，地图变化后重新求路。敌人先按驻点接敌圈及自身攻击/拉扯范围筛选，接敌路径只搜索12格追击预算；这是追击规则，不是算力不足时的降级。

主算法优先保证可达性、路径质量、动态改道和确定性。没有在当前版本加入贪心或固定步数前瞻降级；只有实测整体寻路开销无法满足20 Hz预算时，才评估共享搜索、分摊重算或有明确触发条件的备用策略。不能因为微秒差距就牺牲稳健性，也不使用墙钟耗时分支破坏回放确定性。

测试以固定种子31415生成160组障碍布局，用独立广搜核验首步最短性、行动掩码和不可达结果；连续重规划验证深凹墙、封闭区域及城门打开后的改道，三类战斗兵均做实际移动验证。Release诊断覆盖畅通、小墙障、深凹墙、偏远城门、封闭分区，以及170×170地图60名猎骑同时移动；运行 `rts_tests.exe '[.postbench],[.rangerbench]' --reporter compact`。耗时用于判断可用余量，不替代正确性验收。

本机完整A*诊断：上述五种布局每次查询平均约0.017、0.018、0.054、0.374、0.895毫秒，各80次；60名猎骑在170×170空地图移动200tick共0.109秒，约0.543毫秒/tick。测试包括封闭分区穷尽搜索，但没有模拟大量单位同时在密集后期战场反复请求不可达目标，不能据此保证所有长局的帧率。

## 验证

Release构建启用前端、ONNX、Python绑定和训练集成测试，关闭内部开发工具。测试覆盖冲锋首击/停步/连续攻击、双方创建顺序下的反冲锋、主动接敌与正常阵亡、城门/巷道/封闭路线、迷雾、三种战斗守军的建筑驻守、跨波/改派/目标与单位身份复用、混编驻墙、快照与操作日志重放，并确认兵营不回血、不扣恢复费用。

```powershell
build-verified/tests/rts_tests.exe '[charge],[behavior],[ranger],[guard],[script]' --reporter compact
ctest --test-dir build-verified -C Release --output-on-failure -j 3
```

最终完整A*版本重建后：专项56用例/3042断言通过；全量C++537用例/71527断言通过（184.38秒）。前一轮完整CTest集成157/158项通过，唯一失败为 `rl_suite` 的子进程120秒超时；最终版本单独复跑该项通过（82.28秒），没有放宽超时门槛，也未据此宣称耗时抖动已根治。最新复测命令：

