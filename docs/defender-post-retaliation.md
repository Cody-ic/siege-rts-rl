# 驻军响应圈外攻击

## 问题与修改

实际对局中，猎骑在距驻点约5.84格处交战，另一名距驻点9.10格的法师连续射击它。驻军只把驻点8格内的敌人列为追击目标，近处敌人死亡后便返岗，留下真正的射手。

现在枪卫、猎骑和地面驻守弓手会响应**可见地面敌人对自己、同驻点战友或绑定建筑的直接攻击**。判断读取已经发生的攻击承诺，不根据附近存在法师就臆测其攻击意图。驻墙弓手仍执行原有登墙与射击行为，不为追击自动下墙。

- 普通接敌半径仍为8格；有上述攻击证据时，允许在驻点12格内寻找可达反击位置。
- 12格复用既有追击参数，同时约束从当前位置出发的搜索步数与相对驻点的路线范围，避免每次重算都把追击边界向外移动。
- 每tick观察一次可见的攻击前摇，共享给同驻点单位。记录保留攻击间隔、前摇及一个最长决策周期，跨过冷却期；默认法师约1.9秒，持续攻击会刷新。
- 目标仍须当前可见。停止攻击且记录过期、退出追击范围、死亡或不可达时，按现有逻辑回岗；不读取隐藏敌人的实时位置追踪。
- 来源、受击单位与建筑均保留完整身份。新兵和原址新建筑不会继承旧对象的攻击关系。
- 继续优先处理自身射程内的敌人；本批共享攻击证据，不强制全队同时转火，也不增加回血、自动休整或低血量撤退。

## 兼容性

攻击记录属于守方脚本状态，写入对局快照；普通操作日志可重新产生相同的观察记录。基础存档提升至v39（战术v40、宏观v41），旧存档由对应旧版继续。World/22、Stats/15、动作和观测维数不变；本改动没有更新已安装的试玩程序或真实训练模型。
