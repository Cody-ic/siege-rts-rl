# 墙体与攻城目标修复

本地开发分支，尚未更新玩家正在运行的试玩程序。

## 墙体遮挡

旧渲染器把一整张墙按格心排序。人物即使站在墙外的可通行格，跨过相邻墙段的深度边界时，也可能被截掉半边身体。修复在重叠物件与墙面深度相交处切分贴图，再按局部深度合成；没有交点的墙仍整张绘制。同格双面墙角保留原始接合顺序，防止墙帽交叉露出接缝。

像素尺寸、逐朝向锚点沿用素材元数据，施工、单位坐标和碰撞没有改动。此项解决已复现的遮挡错误，工匠互相重叠另行处理。

## 法师隔墙攻击

建筑目标选择、攻击掩码共用物理射线判定。沿实际射线路过的格检查城墙、城门、木栅栏，穿过格角时检查两侧格，目标自身排除，因此仍能攻击第一层工事。完整工事后的建筑不可直接攻击；拆开缺口后恢复攻击，空军不受地面工事阻挡。

法师前摇结束和弹丸逐段移动时再次检查，防止玩家补墙后旧弹丸继续穿过。已射出的弹丸遇到新墙会消失，不把伤害转给另一座建筑。只检查射程内候选，射线遍历不扫描整张地图。

## 恢复堡垒压力

旧脚本遇到任意可攻击建筑便停下，普通 `AtkBld` 又优先最近目标。现在主攻部队沿既有路径奔堡垒，路线决定破拆还是绕行；能攻击堡垒时，附近兵营不会截走这次建筑攻击。近身接敌仍保留，不死鸟仍执行独立袭击任务。

资源袭扰仅由已有经济分队承担，不再覆盖全部地面部队的意图。默认比例仍是可分派近战队的 25%，向下取整，并至少保留一队主攻，避免小波次被全部分去打矿。此处是行为纠偏，未调整双方血量、伤害、造价；整局难度仍需试玩验证。
