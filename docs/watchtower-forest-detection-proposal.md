# 瞭望塔密林探测与攻击暴露：设计提案

日期：2026-10-12。状态：待评审的设计文档，尚未实现或验证配平。本文只提出视野机制调整，不修改游戏代码、数值表或试玩程序。

## 目标与现状

让瞭望塔成为保护城防、前哨和施工现场的持续观察设施。密林提供隐蔽接近的机会，守方则能通过布置观察点、接近侦查和敌人的出手获得情报。

当前开发分支的瞭望塔视野为12格、零伤害；地面视线经过中间森林格时直接中断，没有独立的近距离揭露或攻击暴露机制。林缘及紧邻格仍可能可见，不能把现状概括为所有林中单位绝对隐身。建筑选敌目前不检查目标可见性，因此森林遮挡观察并不保证免受塔火。

## 瞭望塔探测规则

- 完工瞭望塔在现有12格视野内发现敌军单位；探测视线可穿过密林，仍受岩壁遮挡。采用格心到单位连续位置的实际距离，不扩大成方形范围。
- 发现结果进入守方共享的**单位可见信息**，用于画面、选中、驻军接敌和目标提示。瞭望塔本身不造成伤害，也不增加其他建筑的射程。
- 林中探测不自动揭示整片林区及林后的建筑、施工或经济状态。正常视野与特殊单位探测分别计算，避免把敌人所在格标为全可见而泄露其他实体。
- 未完工时不探测；维修期间继续探测。塔被毁后立即移除其贡献，其他观察者仍能维持发现。重叠探测只共享信息，不叠加范围。
- 不按主城边界裁剪观察者：城外矿区和独立前哨同样有效。沿用静态建筑不得覆盖集结区的地图约束。

首版沿用12格范围及现有价格、建造时间，不另外提高视野或设置升级探测加成。它们仍需在新用途下评估。

## 配套发现机制

| 机制 | 候选规则 | 边界 |
|---|---|---|
| 近距离发现 | 地面单位和完工建筑在2格内发现敌军，密林不阻断此近距探测 | 岩壁仍遮挡；双方适用；2格是候选参数 |
| 攻击暴露 | 单位开始一次有效攻击前摇时暴露，最后一次出手后持续3秒，即60个20Hz tick | 仅下攻击指令但没有合法目标不触发；持续出手刷新时限 |
| 暴露接收 | 攻击者处于敌方合法观察者的普通观察半径内时，可越过密林遮挡被发现 | 不全图广播，不穿岩壁，不泄露旁边其他隐藏单位 |

暴露期间目标在合法观察范围内可被持续观察；离开全部接收范围后不再提供实时位置。再次进入范围时，仅在暴露时限尚有效的情况下重新显现。规则适用于双方战斗单位，空中观察保留已有能力，不扩大成无条件全图探测。

发现规则用于新目标选择；已经发射的弹丸不因目标重新隐藏而凭空消失。是否允许其他形式的失去视野后追踪，需要单独确定，不能由本提案暗中赋予实时情报。

## 与箭塔和攻方决策的关系

**首批增加发现能力；箭塔必须依赖可见目标开火，作为后续独立的配平项。**先验证林中敌人确实有可靠的发现和回击窗口，再决定是否收紧现有选敌。不能同时加强攻方利用密林的能力、取消现有塔火，再用“视野更合理”代替难度验证。

若后续采用可见目标限制，应使用本方共享单位可见信息，而非要求每座箭塔亲眼看见目标。瞭望塔、斥候或驻军提供情报后，射程内且满足攻击许可的塔可以开火；视野发现与弹道能否通过地形仍是不同规则。

攻方应从合法观察与记忆中获得瞭望塔位置，比较开阔路线与密林路线的行军时间、暴露时间、预计承伤和林口条件。已知瞭望塔覆盖范围会削弱隐蔽路线的收益；没见过的塔不能从实时世界偷读。未知区域继续保留不确定性，不默认安全，也不默认被全部探测。

这需要后续调整路线估算；仅增加一个“喜欢树林”的权重无法代表战术完成。当前承伤估算与现有穿地形塔火相匹配，收紧攻击许可时必须同步更新，避免算法奖励实际上没有保护作用的绕路。窥使未交付的情报也不能借共享发现泄露给普通编队。

## 呈现与玩法边界

选中瞭望塔时显示探测范围，并说明“可发现密林中的敌人；岩壁遮挡”。被探测单位需在树冠遮盖下仍有可读的轮廓、血条或目标标记；失去发现后停止显示实时位置。实际提示内容与仿真结果一致，不由渲染器另行判断。

瞭望塔适合覆盖林口、城墙外侧和远矿附近，玩家可以用其他观察者替代部分功能。斥候仍负责移动探索和集结区报告。地图保留开阔进攻路线，避免每一面城墙都必须先买瞭望塔才能正常防守。不得新增针对边缘矿区的地面远征压力。

## 验证与实施顺序

1. 先验证密林探测、近距发现与攻击暴露。覆盖半径边缘、岩壁阻挡、无观察者时不泄露、出手刷新与时限结束、移动出范围、维修及塔毁、双方对称和多个据点。
2. 验证共享发现能进入画面、驻军和目标选择；特殊探测不泄露隐藏建筑。检查敌军藏在树后时，玩家能否实际辨认和选中。
3. 确定性状态记录暴露截止tick及单位身份；槽位复用清零，存档恢复和操作重放保持一致。新增持久状态或规则时按仓库契约更新哈希与存档版本，旧档保留备份。
4. 同地图、同种子和相同防守投入，对照原规则、仅新增发现、再收紧塔选敌三组。优先检查已有挑战的前15波，再检查中后期；记录首次发现到接敌的窗口、塔的有效输出、守军与建筑损失、堡垒承伤以及瞭望塔的投资回报，并由玩家试玩复核。
5. 测量Release下开局和多据点密集场景的视野更新开销。沿用共享观察结果与完整实体扫描的稳健方向，单独处理实体探测权限；既有查询基准不能当作新机制的性能结果。

通过这些验证后，再评估攻方利用遮挡的路线选择、箭塔攻击许可和生成地图的林区位置。3秒暴露、2格近距发现均未标定；本提案不宣称已解决长局平衡。
