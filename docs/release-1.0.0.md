# 1.0.0 发布整合

2026-09-15 按项目成员明确要求整合全部待合并 PR，再发布 Windows 玩家包。
发布分支保留 #163、#174、#178、#180、#181、#182、#183、#184、#185、#186、#187、#189
的原始提交祖先。#179 的剧情彩蛋经 #174 一并进入。

冲突处理保留建造/重叠选择、工匠安全路径、模型输入与恢复、Phoenix 花名册和冷却、
彩蛋触发状态等双方字段及测试。按用户 9/14 的最终决定，日记和彩蛋只属于当前局，
从本局波次、花名册和结局重建；不恢复跨局 journal.json 的自动读写。旧 journal
编解码工具保留以免删除历史材料。存档统一升为 v6，拒绝 v3/v4/v5，保留 legacy 备份。

正式包不包含源码、Python、训练目录、模型检查点、构建中间文件或预览素材。
默认脚本攻方未改变；所有 RL 实验失败和局限仍保留在原报告中，代码整合不代表
候选模型通过效果门槛。不死鸟已发布的固定阈值机制被整合，不宣称额外完成尚未实现的自适应配平。

发布构建：Windows/MSVC x64 Release，渲染、ONNX、绑定和训练回归开启。
首轮 186 项测试中，36 项原生测试被重复注册的同一保存测试阻断；另外一项测试
对 Windows 长短路径作了文本比较。删除经确认完全相同的重复项并对路径规范化后
重跑失败项。完整最终结果、验证范围和发布包 SHA256 见 Release 说明。

包外验证使用工程目录之外的中文加空格路径，由 GUI 启动器启动；隔离 LOCALAPPDATA，
素材根实际命中解压目录。内置字体为 OFL Noto Sans SC 的 400 字重静态实例，
运行库来自 MSVC 可再分发目录和 ONNX Runtime CPU SDK。所有文件在 manifest.json
记录 SHA256。程序未做 Authenticode 签名，没有声称在全新 Windows 虚拟机完成测试。
